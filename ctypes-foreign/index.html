Library ctypes-foreign

This library exposes the following toplevel modules:

  • Ctypes_closure_properties
  • Ctypes_ffi
  • Ctypes_ffi_stubs
  • Ctypes_foreign_basis
  • Ctypes_weak_ref A single-cell variant of the weak arrays in the standard library.
  • Dl Bindings to the dlopen / dlsym interface.
  • Foreign High-level bindings for C functions and values
  • Libffi_abi Support for various ABIs.
